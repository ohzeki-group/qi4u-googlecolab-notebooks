# About this repository
This repository consists of jupyter notebooks and slides that were introduced during _Introductory workshop on Quantum Computing_, held at the University of Warsaw, Poland on 3--5 March 2026:

 - Quantum annealing hands-on materials
   - Slides (`QA_hands_on_slides.pdf`)
   - Workload scheduling problem (`QA_hands_on.ipynb`)
   - Black-box optimization with simulated quantum annealing (`Black-box_optimization_with_SQA_demo.ipynb`)
 - Gate-based quantum computing hands-on materials
   - Slides (`Gate_based_lecture_taisei.pdf`)
   - Introduction to Qiskit (`Poland_basic_ideas_of_qiskit.ipynb`)
   - Quantum Born machine (`Poland_Quantum_Born_machine.ipynb`)

Jupyter notebooks need a python environment with jupyter notebook/lab or can work on Google Colaboratory (Google account required). The notebooks are also available on the [workshop website]() via nbviewer.
