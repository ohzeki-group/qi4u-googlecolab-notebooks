# About this repository
This repository consists of jupyter notebooks and slides that were used during the workshop:

 - Quantum annealing hands-on
   - Workload scheduling problem (+ slides)
   - Black-box optimization
 - Gate-based quantum computing
   - Introduction to Qiskit (+ slides)
   - Quantum Born machine (+ slides)

Jupyter notebooks need a python environment with jupyter notebook/lab or can work on Google Colaboratory (Google account required). The notebooks are also available on the [workshop website]() via nbviewer.
